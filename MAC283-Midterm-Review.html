Computer Architecture Basics

Review: Know the job of each major component (CPU, ALU, RAM, storage) and the defining idea of the Von Neumann architecture: instructions and data live in the same memory.
02

Number Systems: Binary · Decimal · Hex · Octal

Review: Binary→decimal: add place values (…8, 4, 2, 1). Binary→hex: group in 4 bits from the right. Binary→octal: group in 3 bits from the right. Decimal→binary: repeated division by 2, read remainders bottom-up.
03

Signed Number Representation

Review: Sign-magnitude → leftmost bit is the sign. One's complement → flip every bit. Two's complement → flip every bit, then add 1. In two's complement, −1 is always all 1s.
04

Floating Point & Character Encoding

Review: IEEE 754 is the standard for floating-point numbers (sign · exponent · mantissa) — it trades exact precision for a huge range. Standard ASCII uses 7 bits = 128 characters.
05

Boolean Algebra Laws

Review: Absorption: A + A·B = A and A·(A + B) = A. Complement: A + A' = 1, A·A' = 0. DeMorgan: (A·B)' = A' + B' and (A + B)' = A'·B'.
06

Logic Gates

Review: XOR outputs 1 only when inputs differ. NAND/NOR are the inverted versions of AND/OR. Build the truth table if you're ever unsure.
07

K-Maps & Sum of Products

Review: A K-map has 2ⁿ cells for n variables. Σ(...) lists the minterm numbers where F = 1. Group 1s in powers of two (1, 2, 4, 8…) to simplify; bigger groups mean simpler terms.
08

Applied Logic (Word Problems)

Review: Translate English into operators: "and" → ·, "or" → +, "not / is 0" → '. "Only if X and not Y" becomes X·Y'.
09

Binary Arithmetic

Review: Add column by column from the right: 1+1 = 10 (write 0, carry 1), 1+1+1 = 11 (write 1, carry 1). Track your carries carefully — that's where points are lost.
